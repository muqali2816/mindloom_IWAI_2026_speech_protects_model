## 2. Camera-ready: жёсткие требования и структура

**Требования IWAI 2026 (сайт воркшопа):** full paper — до 12 стр. LNCS без списка литературы; приложение — до 12 стр.; camera-ready загружается на OpenReview как PDF + **zip с исходниками** (LaTeX LNCS) + подписанная форма копирайта Springer. Организаторы сверяют camera-ready с подачей.

Следствия для текущей версии:

1. **Объём.** Основной текст сейчас ~20 стр. → нужно ≤ 12. Реалистичное распределение: Введение 1.5 · Scope 0.5 · Часть I (аннотация + результаты) 2.5 · Часть II модель 2 · результаты 3 · roadmap 1 · обсуждение/заключение 1.5. В приложение (≤ 12 стр.): формальные детали A1–A2, история сборок B1, робастность B2, статус воспроизводимости B3, полная дорожная карта 7.3–7.5, диалог-иллюстрация.
2. **Формат.** Исправленная версия, судя по вёрстке, сделана не в LNCS-шаблоне (нумерация формул отсутствует, интервалы, таблицы). Zip с исходниками обязателен → переносить в `llncs.cls`. Формулы пронумеровать (1)–(5).
3. **Узнаваемость.** Заголовок подачи: «Speech that Protects a Model: A Type-Safe Active-Inference Engine for Compensatory-Defensive Discourse». Новый подзаголовок убирает «type-safe engine», а именно его чairs назвали «promising». Рекомендуемый компромисс: «Speech that Protects a Model: Typed Dialogue Evidence and an Active-Inference Test of Competing Mechanisms». Сохранить ключевые слова подачи (active inference, dyadic inference, compensatory-defensive speech, type safety).
4. **Не превратить статью в отчёт об аудите.** Убрать из основного текста: «forensic note», «combined engine JSON», «May 17 build», «July archive», «September 28 revision», «gates-off capture», «author-reported result». Всё это — в B1/B3 или в README пакета. Оставить одно предложение: «Numbers in this version are re-scored from archived predictions; the 87.2 % figure of the submitted version referred to an earlier build and a different aggregation (Appendix B1)».
5. **Аннотация ≤ 200 слов, без «Mindloom» как субъекта, по одному числу на часть:** движок = прямой промпт по точности (0.852), уступает по macro-F1; единственное кандидатное преимущество — заземление: 17/65 несостоятельных мостов в gates-off прогоне (перепроверяемо), снятие всех 17 гейтом — author-reported, из пакета не воспроизводится, формулировать только с этой оговоркой; модель: 0.989 vs 0.990 непризнание при 0.538 vs 0.809 p_true. Убрать «allostatic load» из аннотации и keywords (оставить одно предложение в future work).
6. **Обязательные элементы Springer:** Data/code availability **с URL или DOI (Zenodo)** — сейчас адреса нет; Disclosure of Interests; ORCID можно оставить.
7. **Три технических уточнения, которые обязательно попросит внимательный читатель IWAI** (по 1–2 предложения каждое): при c > b CONCEDE никогда не минимизирует ожидаемую стоимость (значит высокое непризнание в этом условии — следствие выбора c относительно b); при ω → 0 ренормировка A_ω делает субъективную частоту прихода свидетельств равной 2/3 независимо от λ (влияет на IG у ASK); строка «late non-concession — power 0.13» в Табл. 6 — по конструкции матчинга, пометить.
8. **Одна новая фигура вместо строки текста:** кривая диссоциации по уровням матчинга 0.70–0.99 (разрыв в убеждении 0.032 → 0.270, разрыв в ASK 0.007 → 0.099). Данные уже посчитаны (пункт 6 вашего плана).

**Колонка 2 — Центр: Fig. 1 (траектории p_true + ставки действий).** Подпись из трёх строк: матчинг 0.989 vs 0.990; p_true 0.538 vs 0.809; ASK 0.05 vs 0.15. Ниже — маленькая схема генеративной модели (x → e; ω; c; ASK → λ).

**Колонка 3 — Что различает механизмы.**

## 4. Spotlight (обычно 3–5 минут, 1–3 слайда)

Одна мысль, одна фигура, один вывод.

- **Слайд 1 (30 с).** Вопрос: Friston & Frith объясняют, как диалог сближает модели; что происходит, когда диалог продолжается, а ожидание не пересматривается? Два кандидата-механизма: слабая чувствительность к свидетельству (ω) vs цена публичной уступки (c).
- **Слайд 2 (2 мин).** Fig. 1. «Подобрали два агента с одинаковым непризнанием 0.99. Один почти не изменил убеждение (0.54), другой — почти полностью (0.81). Сводка по речи не различает; различают: история свидетельств, приватное убеждение, снятие штрафа (0.06 → 0.43)».
- **Слайд 3 (1 мин).** Что это значит для аннотации речи: без гейтов 17 из 65 меток манипуляции ссылались на отсутствующее свидетельство; гейт по нашим записям снимает их, но это пока не перепроверено независимо — а по точности движок не лучше прямого промпта — и даже идеальная метка не скажет, какой из механизмов работает. Поэтому следующий шаг — человеческий эксперимент с приватными убеждениями и рандомизированным штрафом (17–25 диалогов на группу в симуляции).
- **Закрывающая фраза:** «Active inference here is a test bed for identifiability, not a decoration: we measured what it adds (17 % of one contrast) and what it does not».

Не говорить в spotlight: про сборки, форензику, аллостаз, P/T/M. Вопросы про «AI decorative» (Whwy/Zctq) встречать готовым ответом: ablation IG + таблица моста.

| Вопрос TF6t-2 | Ответ по данным |
|---|---|
| Тип случаев | Все 589 — `document_type: monologue_fragment`, один говорящий, без реплик адресата. Tier A: 35–71 слово (медиана 50); Tier B: 1–47 слов (медиана 15) |
| Источники | Три авторских корпуса: `corpus_ood_regime_en_200` (169, Tier A), `corpus_d_defense_en_run_4mon` (265, B), `corpus_ood_defense_en_200_v_2` (155, B) |
| Точные дубликаты | 0 |
| Near-duplicates (5-граммы слов, Jaccard) | Tier A: 0 пар при J ≥ 0.2. Tier B: 15 пар при J ≥ 0.3; 11 из 155 одноимённых пар `4mon_NNN`/`ood_NNN` — расширения одного текста (пример: `ood_089` = `4mon_089` + одно предложение). Т. е. 2.6–3.6 % Tier B — шаблонные варианты |
