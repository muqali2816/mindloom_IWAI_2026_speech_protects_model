## 1. Что заявляет статья

1. **Часть I (аннотация речи).** Пятиуровневая типизированная схема (L1–L5), 5 операций (PUSH/PULL/SEEK/DRIFT/BLOCK), 8 конфигураций + SEAL + SHIFT. Пилот 6 непрофессиональных аннотаторов: α = 0.437 (MASI), Jaccard 0.832, 71.9 % совпадения с ключом координатора; каппа по признакам от 1.000 до −0.111. Пересчёт 169 архивных случаев: типизированный движок macro-F1 0.757 vs прямой промпт 0.837; SHIFT recall 2/20 vs 18/20.
2. **Часть II (модель).** Одноагентная дискретная модель с бинарным скрытым состоянием, тремя исходами наблюдения, пятью действиями, одношаговым EFE = ожидаемая стоимость − информационный выигрыш, softmax τ = 0.20, 12 раундов. Сравнение «ослабление правдоподобия» (ω = 0.10) и «стоимость уступки» (c = 1.4), подобранных по позднему непризнанию (0.989 vs 0.990): финальная p_true 0.538 vs 0.809; удаление IG сохраняет ~83 % контраста по ASK; восстановление семейства 0.70–0.87; интервенции разделяют «выражение» и «обновление».
3. **Дорожная карта** (разд. 7): валидация аннотации, человеческий эксперимент с приватными убеждениями, режимы/прогноз, физиология/аллостатическая нагрузка.

## 2. Актуальность и новизна

**Актуальность.** Тема на стыке дискретного active inference, прагматики диалога и компьютерной психопатологии. Опора на Friston & Frith [1, 2], Friston et al. 2020 [3], Medrano & Sajid [17], Prosser et al. [14] — корректная и своевременная. Вопрос «что active inference добавляет к expected-cost-only модели» — сам по себе актуальный для сообщества IWAI, и статья на него честно отвечает (добавляет ~16.7 % контраста по ASK).

**Новизна — ограниченная.**
- Центральный тезис (публичное непризнание не идентифицирует механизм) — частный случай классической неидентифицируемости «prior/likelihood vs preference/utility» в POMDP; статья сама признаёт, что не вводит новых механизмов (стр. 4). Вклад — не новая идея, а *чистая иллюстрация* с восстановлением параметров и ранжированием каналов измерения.
- Модель минимальна по стандартам IWAI: один агент, среда — фактически стохастический источник свидетельств; нет B‑матрицы, нет иерархии, нет обучения параметров, нет второго агента (оба ключевых источника [1, 17] — диадные). Двухшаговая политика и адаптивный поставщик свидетельств вынесены в приложение B и описаны одним абзацем.
- Ослабление правдоподобия через экспоненту ω (precision) — стандартный приём [14–16]; стоимость действия c — стандартная предпочтительная переменная. Новое — только их *сопоставление* при матчинге по одной сводной метрике.
- Часть I новизны для IWAI не несёт: LLM‑классификатор с онтологией уступает голому промпту, а его «уникальное преимущество» (заземление: 17/65 несостоятельных мостов сняты гейтом) не может быть перепроверено из пакета (стр. 9).

Реалистичная формулировка вклада: *«калибровочная демонстрация неидентифицируемости и предварительный дизайн измерений для человеческого исследования»*. Это уровень воркшопа, но не полноценной journal‑статьи.

## 3. Ошибки, неточности и логические проблемы

### 3.1 Логика и дизайн (существенные)

1. **Круговая «мощность» для позднего непризнания (Табл. 6, §6.5).** Условия *подобраны* так, чтобы совпадать по позднему непризнанию (0.989 vs 0.990). Тогда «не достигнуто; мощность 0.13 при 3 200» — не результат, а следствие конструкции. Вывод «исследование, основанное только на непризнании, неэффективно» верен только в пределах матчинга. Нужно либо убрать эту строку, либо явно назвать её проверкой корректности матчинга.
2. **Экстремальность ω = 0.10 делает диссоциацию почти тавтологичной.** При ω = 0.10 каждое наблюдение сдвигает логит на 0.1·ln 3 ≈ 0.11; за 12 раундов абсолютное изменение убеждения 0.051 — агент практически не обучается. Сравнение сводится к «не обучающийся агент vs обучающийся, но не признающий». Перематчинг 0.70–0.99 (стр. 14) отчасти спасает, но при 0.70 разрыв убеждений всего 0.032 — это надо показать таблицей/графиком, а не одной строкой.
3. **При c = 1.4 > b = 1.10 действие CONCEDE никогда не является дешевейшим** (его стоимость k·q + c ≥ 1.4 при любом q). Высокое непризнание в этом условии — арифметическое следствие выбора c относительно b, а не эмерджентное свойство. Это нигде не сказано явно; читатель должен вычислить сам. Аналогично при ω = 0.10 (q ≈ 0.75): ASSERT = 0.5, прочие = 1.10, CONCEDE = 1.5 — доминирование ASSERT предопределено.
4. **Формула субъективного правдоподобия имеет побочный эффект, не обсуждённый в тексте.** A_ω ∝ A^ω с ренормировкой по e: при ω → 0 все три исхода субъективно равновероятны (по 1/3), т. е. агент верит, что свидетельство приходит с вероятностью 2/3 независимо от λ. «Ослабление точности» тем самым смешивается с искажением ожидаемой частоты прихода свидетельств, что напрямую влияет на I_ω(q, ASK) и, следовательно, на сравнение ASK‑ставок между механизмами (§6.2). Фраза «also changes subjective arrival predictions through normalisation» (стр. 10–11) это констатирует, но не оценивает. Нужна либо альтернативная параметризация (ослаблять только ρ, оставляя λ), либо ablation.
5. **PRESSURE в базовой модели инертен** и по стоимости идентичен SILENCE; следовательно, три «нефактических» действия отличаются только IG у ASK. Тогда «поведенческая сигнатура» через ASK — артефакт меню действий, что и подтверждает эксперимент с b − g·c (Приложение B2: контраст по ASK −0.013, по PRESSURE +0.411). Статья это признаёт, но продолжает использовать ASK‑контраст в Табл. 6 как рекомендуемый канал измерения (53 диалога на группу). Рекомендация непереносима.
6. **Оценки параметров практически равны априорному среднему.** MAE для c при аттенюационном генераторе 1.394 при априорном среднем сетки 1.5 — т. е. наблюдатель о c не узнаёт ничего; MAE для ω 0.264–0.398 при неинформативном ~0.45. В тексте это названо «weak», но следовало бы сказать прямо: «оценка совпадает с априором». Иначе Табл. 5 читается как частичный успех.
7. **Точка (ω = 1, c = 0) входит в оба семейства.** При равных априорах семейств это создаёт перекрытие масс; корректнее исключить референсную точку из обоих или дать ей отдельную «нулевую» гипотезу.
8. **Взаимосвязь частей заявлена и сразу отозвана.** Стр. 5: «They are not yet a fitted pipeline… The simulation neither generates Mindloom configurations nor estimates mechanisms from them». Тогда для читателя IWAI Часть I — 4 страницы (7–10) без функции в аргументе; единственная связка — «даже надёжно наблюдаемый отказ не раскрывает причину», для чего Часть I не нужна.
9. **Сравнение движка и прямого промпта не контролируемо по признанию автора** (разные модели, движок может воздерживаться, baseline — нет; провайдер движка не подтверждён). Тогда Табл. 3 нельзя интерпретировать ни в одну сторону, и включение её в основной текст лишь порождает вопросы.
10. **Аллостатическая нагрузка** (аннотация, ключевые слова, §2.2, §7.4, ~2 страницы) — гипотеза без единого измерения в статье. Для IWAI это шум; для аннотации — неоправданное расширение заявки.

### 3.2 Формальная часть (проверено)

- Логит‑рекурсия logit(q_t) = logit(q_0) + ω·m_t·logit(ρ) — **верна**: нормировочные константы A_ω для x = 0 и x = 1 совпадают, отношение правдоподобий для e = 1 равно (ρ/(1−ρ))^ω, нулевое наблюдение даёт отношение 1.
- Формула свободной энергии (Прил. A1) и формула взаимной информации — **верны**.
- Утверждение «F = KL от точного постериора минус log evidence» — верно.
- Согласованность чисел: 145 = 127 + 18; 129 = 127 + 2; 0.0828 + 0.0166 = 0.0994 ≈ 0.150 − 0.050; 0.2704 ≈ 0.809 − 0.538; 17 + 1 + 2 = 20 (SHIFT) — **всё сходится**.
- Начальная p_true = 0.5 (q_0 = 0.75, x ~ Bernoulli(0.5)), финальная 0.538 при аттенюации — согласуется с абсолютным изменением 0.051.
- «Approximately 16.7 % of the full late contrast» — 0.0166/0.0994 = 0.167, верно, но следует уточнить, что речь о контрасте *по ASK*, а не о «полной диссоциации».
- Формулы не нумерованы; в LNCS для ссылок на них нужна нумерация.

### 3.3 Неточности, терминология, оформление

- **«Mindloom» как субъект действия** («Mindloom specifies…», «classified by Mindloom», «Mindloom labels», «Mindloom features») — 20+ вхождений. Это название лаборатории/продукта; для двойного слепого рецензирования недопустимо, а в проходящей публикации читается как брендинг. Заменить на «the annotation scheme / the typed engine».
- **Деанонимизация**: имя, ORCID, лаборатория, email на стр. 1; самоцитирования [4, 5, 18, 21] с формулировкой «Earlier papers in the Mindloom programme». Если версия предназначена для слепого рецензирования — критический дефект; если это camera‑ready — снять комментарий.
- **Внутренний провенанс‑нарратив** («forensic note», «the baseline JSON identifies Claude Haiku 4.5», «the combined engine JSON does not contain a provider field», «May 17 build», «July archive», «September 28 revision», «Sonnet 4.6 run», «gates‑off capture») — уместен в CHANGELOG пакета, не в статье. Занимает ~1.5 страницы.
- **Табл. 2** ссылается на «Section 5.3 and Table 4, page 8» *внешнего* отчёта — читатель без отчёта не может это проверить; заменить на ссылку [22]‑типа или убрать.
- **Data and code availability** не содержит URL/DOI пакета. Для IWAI (Springer CCIS) это обязательный элемент; фраза «accompanying package» без адреса эквивалентна отсутствию кода.
- Отсутствуют разделы **Disclosure of Interests** и (при необходимости) Ethics — требуются шаблоном LNCS/CCIS.
- Аннотация 230 слов, 11 числовых значений и брендовое имя; «supporting an inspectable annotation proposal rather than superior classification» — двойное отрицание вклада. Для IWAI (лимит в прошлых CFP — 150–250 слов) сократить до одного числового результата на часть.
- «Fig. 1» / «Fig. 2» — подписи корректны, но графики не воспроизведены в тексте (text‑layer); убедиться, что в финальном PDF разрешение достаточно для печати.
- Термин «temporal regime» вводится, затем пять раз оговаривается, что режимы не установлены; проще не вводить.
- Раздел 1.1 (сконструированные диалоги) — полезен как иллюстрация, но занимает целую страницу; для 12‑страничного формата — 5–6 строк.

## 4. Сильные стороны (что сохранить)

- Дисциплинированное различение трёх «стоимостей» (уступка / поддержание / аллостатическая нагрузка) — редкая ясность в этой литературе.
- Ablation информационного выигрыша с честным выводом, что active inference добавляет прирост, а не объяснение. Такая честность ценна для IWAI.
- Спаренные миры (shared random numbers), явные Монте‑Карло интервалы, разделение задач «выбор семейства / оценка параметров / прогноз действия / мощность» — методически корректно.
- Чувствительность наблюдателя к k и τ (0.07 vs 1.00) — важное предостережение, его стоит вынести в основной результат, а не в конец §6.3.
- Раздел 7.2 (дизайн человеческого эксперимента с приватными убеждениями и рандомизированным снятием штрафа) — конкретен и осуществим.
