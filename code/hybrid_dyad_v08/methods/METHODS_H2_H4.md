# METHODS — трек B: H2 (восстановление механизма по каналам) и H4 (чувствительность знака контрастов)

Гибридная диадная модель v0.8 (`hybrid_dyad/`): core.py и observer.py не менялись. Все числа ниже взяты из сохранённых CSV в `results/`. Это симуляция заданных механизмов; никаких утверждений о людях.

## H2. Условия и процедура

- Миры: `hd.make_worlds(2000, seed=20261012)` (protocol.json['seeds']['H2']), N=2 приватных записи, 12 раундов, одновременные ходы. Метки: `hd.emit_labels(d, seed=20261015)` — строки LOCK/SEEK на каждый мир из Dirichlet(counts+0.5).
- Генераторы A (партнёр B): honest×honest, attenuated×honest, costly×honest, access×honest, mixed×honest, access×access, costly×costly. Восстанавливается A; наблюдателю передаётся `spec_B` = истинные параметры B.
- Каналы `observer.recover`: `acts` (акты + запись свидетельств), `labels` при η ∈ {0, 0.25, 0.5} (C = `hd.channel_mean(η)`), `oracle` (истинные формы), `null_labels` (метки, зависящие только от акта ASK; контроль), `labels` при η = 1 (контроль: строки совпадают → метки неинформативны). Все каналы на 2000 мирах, кроме η = 1 (первые 1000 миров).
- Гипотезы наблюдателя (`observer.hypotheses()`): 8 уникальных: attenuation {ω∈{0.2,0.6,1}}, cost {c∈{0,0.8,1.6}}, access {γ∈{0,1,2,4}}; референс (1,0,0) общий для трёх семейств. Априорное среднее по уникальным гипотезам: ω=0.85, c=0.30, γ=0.875 — базовая MAE = |априор − истина|.
- Метрики: correct_family = доля миров с argmax family_post на истинном семействе; posterior_on_family = средний постериор истинного семейства; MAE ω/c/γ (постериорное среднее против истины) рядом с базовой MAE априора; потери next-signal (`run_utils.logloss_signal`, среднее по целям e_2..e_12) и next-act A (`run_utils.logloss_act`), прирост = потери(acts) − потери(канал) в натах на исход, бутстрап по мирам (1000 повторов, seed 20261012); доля информации оракула = gain(labels)/gain(oracle) с бутстрап-интервалом того же ресемплинга.
- Срезы: все миры и A_own0==1 (A стартует на своей стороне; 1360 из 2000 миров).
- Время: ~52.3 с на канал (2000 миров), 7 генераторов параллельно; см. `results/H2_timing.json`.

### Контроли (`results/H2_controls.csv`)

- null_labels == acts: max |Δ family_post| ≤ 7.1e-15, max |Δ next_sig| ≤ 1.6e-15 по всем 7 генераторам (порог 1e-9) — пройдено.
- labels η=1 == acts (1000 миров): max |Δ next_sig| ≤ 1.5e-15, прирост меток = 0 с точностью 5.5e-18 — пройдено.
- oracle ≥ labels по next-signal gain: выполняется для всех 7 генераторов; по correct_family — для всех 5 генераторов с определённым семейством и всех η.

## H4. Условия и процедура

- Сетка: τ ∈ {0.1,0.2,0.4} × δ (restriction_cost) ∈ {0.06,0.12,0.24} × λ_floor ∈ {0.02,0.05,0.10} × N ∈ {2,4} = 54 настройки; параметры менялись через `hd.P[...]` (контекст-менеджер с восстановлением), N — аргумент `make_worlds`. 1000 миров на настройку, seed 20261014 (protocol['seeds']['H4']); при каждом N миры генерируются заново тем же seed. Партнёр honest; A ∈ {honest, attenuated, costly, access}.
- Контрасты (парные по общим мирам, 95% MC-интервалы): access−honest по evidence_count и A_p_truth; costly−attenuated по A_dbelief; access−costly по restrict_A. Срезы: все миры и A_own0==1. Смена знака — относительно настройки по умолчанию (τ=0.2, δ=0.12, λ_floor=0.05, N=2).
- Прирост меток: 6 настроек — крайние значения по одному параметру при остальных по умолчанию и N=2 (τ=0.1, τ=0.4, δ=0.06, δ=0.24, λ_floor=0.02, λ_floor=0.10); 500 миров, каналы acts и labels η=0.25, все 4 генератора; next-signal gain с бутстрапом (1000 повторов).
