# Гибридная диада v0.8: речь как свидетельство для партнёра и как управление доступом к совместной проверке

Mindloom • 30 сентября 2026 • статус: результаты заданных вычислительных механизмов; не данные людей; локальная предспецификация (protocol.json, предсказания P1–P4 записаны до прогонов), не внешняя пререгистрация. Валидация 10/10, включая две бит‑в‑бит регрессии: к M‑bridge (акты, формы, сигналы идентичны; убеждения ≤ 1e‑15) и к v0.7 (акты идентичны; убеждения ≤ 3e‑12).

## 1. Что объединено

| компонент | из M‑bridge | из v0.7 |
|---|---|---|
| выбор акт × форма (приглашение / ограничение проверки) | да | — |
| совместная форма гейтирует общее свидетельство, λ = 0.05 + (λ_base − 0.05)·f_A·f_B | да | — |
| γ — избегание ожидаемого публичного опровержения | да | — |
| речь партнёра как свидетельство о факте (level‑1 апостериор по x, s_j, c_j, ω_j) | — | да |
| REASSURE (снимает цену уступки партнёра), плацебо | — | да |
| параметры (ω, c, γ) per‑agent, смешанные пары | — | да (расширено) |
| метки = строки LOCK/SEEK матрицы ошибок движка (15 и 20 случаев) | да | — |
| неопределённость строк — Dirichlet(counts + 0.5) по мирам | новое | |
| точный наблюдатель: HMM по (x, s_A, s_B, пара форм) + детерминированный replay level‑1 агентов | новое (объединяет фильтр M‑bridge и replay v0.7) | |

ω шкалирует логит‑приращения от **всего**, что приносит диалог: общие сигналы (это arrival‑preserving ρ_ω из M‑bridge) и акты партнёра (marginal‑shrink из v0.7). Партнёр моделируется как level‑0 **без форм** — это условие точности внешнего наблюдателя (MODEL_SPEC §5, §7). Типы: honest (1,0,0), attenuated (0.2,0,0), costly (1,1.6,0), access (1,0,2), mixed (0.6,0.8,1). N = 2 приватные записи, 12 раундов, одновременные ходы, β = 1.5, 2000 миров на условие.

## 2. H1 — три механизма, три канала (seed 20261011; Fig. H1_channels, POSTER b)

Срез «A стартует за свою версию» (n = 1381), партнёр честный:

| канал | honest | attenuated | costly | access |
|---|---|---|---|---|
| позднее непризнание A | 0.794 | **0.981** | **0.996** | 0.814 |
| \|Δ приватного убеждения\| | 0.227 | **0.066** | 0.238 | 0.208 |
| скрытый сдвиг (убеждение сдвинулось, позиция та же) | 0.083 | 0.057 | **0.222** | 0.082 |
| общих сигналов за диалог | 2.64 | 2.58 | 2.73 | **2.09** |
| доля ограничивающих форм A | 0.335 | 0.354 | 0.336 | **0.526** |
| p_true A в конце | 0.850 | 0.727 | 0.859 | 0.828 |
| частота ASK у A | 0.030 | 0.025 | 0.070 | 0.022 |

Ослабленный и ценовой агенты публично неразличимы (0.98 vs 1.00), но первый не учится (Δ 0.07), второй учится и скрывает (сдвиг 0.22). Агент, защищающий доступ, учится нормально (ω = 1), но устраивает так, что проверять почти нечего: сигналов −0.55 за диалог, ограничений +0.19; его убеждение страдает умеренно (p_true −0.022), потому что речь партнёра остаётся для него свидетельством — именно это добавляет v0.7‑канал к M‑bridge (там падение было −0.05).

**P1 частично подтверждена**: разделение по каналам — как предсказано; но «одинаковое непризнание» достижимо только для attenuated и costly — γ ∈ {1…8} не поднимает непризнание выше 0.83 (≈ honest). Защита доступа — механизм не публичного упорства, а *обеднения проверки*. **P2 подтверждена**: access × access — минимум сигналов среди 16 пар (1.75 против 2.60 у honest × honest); одного access достаточно, чтобы снизить сигналы пары до 1.98 (правило произведения); разрыв убеждений aa 0.138 > hh 0.122 (CI [+0.008; +0.025]); оговорка: наибольший разрыв даёт attenuated × attenuated (0.285). Абляция β = 0: сигналов −0.08…−0.15, остальное ≤ 0.02 — информационный член вносит малый вклад, ранжирование каналов сохраняется.

## 3. H3 — интервенции и каналы измерения (seed 20261013; Fig. H3_*, POSTER d)

Парные контрасты к базе, срез A_own0 (плацебо = REASSURE партнёра без снятия цены; «чистый» эффект рамки = reassure − placebo):

| интервенция → исход | honest | attenuated | costly | access |
|---|---|---|---|---|
| рамка − плацебо → P(уступка A в 8–12) | 0 | 0 | **+0.155** | 0 |
| снятие c → P(уступка) | 0 | 0 | **+0.275** | 0 |
| снятие γ → сигналы в 8–12 / доля ограничений | 0 | 0 | 0 | **+0.199 / −0.187** |
| принудительная открытость партнёра → сигналы в 8–12 | +0.319 | +0.312 | +0.333 | +0.127 |
| общее сильное свидетельство (ρ = 0.95) → p_true A | +0.107 | **+0.058** | +0.092 | +0.120 |

**P4 в основном подтверждена**: рамка и снятие цены двигают только costly; снятие γ — только access; сильное свидетельство меньше всего двигает attenuated. **Опровергнута** часть «принудительная открытость партнёра двигает только access»: сигналы растут у всех типов, у access — меньше всего (+0.127), и он в ответ ограничивает ещё сильнее (+0.067) — открытость одной стороны компенсируется закрытостью другой. Слушатель B по актам распознаёт costly (P(c_A = 1.6) = 0.45 против 0.23–0.32) и attenuated (P(ω_A = 0.2) = 0.59 против 0.42–0.47), но не access (≈ honest): защита доступа видна партнёру только через формы, которых нет в его level‑0 модели.

**Диалогов на группу для мощности 0.8** (Welch, α = 0.05, A_own0): attenuated vs costly — |Δ убеждения| 17, P(true ω_A) слушателя 12, непризнание 200; attenuated vs access — доля ограничений 12, P(true ω_A) 12; costly vs access — доля ограничений 12, P(c_A = 1.6) слушателя 12, непризнание 25, а приватное убеждение не различает (> 400). Каждый механизм имеет свой дешёвый канал; ни один канал не различает все три пары.

## 4. H2 — восстановление по актам, меткам и оракулу форм (seed 20261012; Fig. H2_*, POSTER c)

| генератор A (партнёр честный) | акты + сигналы | + метки η = 0.25 | + оракул форм |
|---|---|---|---|
| attenuated | 0.612 | 0.672 | 0.678 |
| costly | 0.690 | 0.765 | 0.785 |
| access | 0.681 | 0.756 | 0.812 |
| access × access | 0.630 | 0.711 | 0.762 |
| costly × costly | 0.700 | 0.762 | 0.786 |

Метки форм повышают верное семейство на +0.06…+0.08 у всех генераторов; наибольший прирост постериорной массы — у access (+0.141 против +0.012 у costly): его сигнатура — форма. Прирост прогноза следующего сигнала: 0.044–0.085 нат/исход при η = 0.25 (оракул 0.073–0.161); метки передают 53–61 % информации оракула при η = 0.25, 59–67 % при η = 0, 38–47 % при η = 0.5 (**P3**: качественные части подтверждены; предсказанная доля 0.25–0.5 достигается только при η = 0.5). Контроли: null‑метки (зависят только от акта) = акты до 7e‑15; η = 1 — прирост 0 (1.5e‑15). У honest по одним актам наблюдатель кладёт 0.40 массы на семейство access (γ > 0 невидим без форм); метки возвращают массу к ослаблению (0.38). Прогноз следующего акта метки почти не улучшают (≤ 0.006 нат). MAE постериорных средних не монотонна по информации (γ: 0.80 → 0.85 → 0.88 при априоре 1.125) — семейство распознаётся лучше, чем оценивается величина.

## 5. H4 — чувствительность (seed 20261014; 54 настройки τ × δ × λ_floor × N, 1000 миров)

0/54 смен знака для всех четырёх ключевых контрастов на обоих срезах: access − honest по сигналам (−0.22…−1.72) и по p_true (−0.005…−0.055; CI включает 0 в 1/54 all и 12/54 A_own0 — все при N = 4 или τ = 0.4; самый слабый контраст); costly − attenuated по |Δ убеждения| (+0.118…+0.186); access − costly по доле ограничений (+0.096…+0.478). Прирост от меток положителен во всех 24 угловых настройках (0.033–0.084 нат).

## 6. Что установлено и что стипулировано

Установлено внутри симулятора: (а) три механизма с разными сигнатурами — чувствительность, скрытый сдвиг, доступ; публичное упорство даёт только два из них; (б) речь партнёра как свидетельство смягчает ущерб от защиты доступа (p_true −0.022 против −0.05 в M‑bridge); (в) партнёр‑слушатель — измерительный прибор для цены и ослабления, но слеп к защите доступа; (г) метки форм — измерение поведения с заданными последствиями — дают воспроизводимый прирост и для восстановления механизма, и для прогноза сигналов, с точными нулевыми контролями; (д) интервенции разделяют механизмы: рамка/цена → costly, снятие γ → access, сильное свидетельство → attenuated; открытость одной стороны компенсируется закрытостью другой.

Стипулировано и не проверено: влияние формы на доступ (правило произведения); перенос строк LOCK/SEEK (15 и 20 случаев) на диалоги; level‑0 модель партнёра без форм (ложна по построению); γ относится к исходной позиции; нет обучения, рекурсии, естественного языка. Ни одна величина — не утверждение о людях. Отклонения треков: калибровка равного непризнания недостижима для access (основное сравнение при типовых параметрах); контроль «принудительное молчание» заменён на плацебо; η = 1 — на 1000 мирах; mixed добавлен вне сетки гипотез.
