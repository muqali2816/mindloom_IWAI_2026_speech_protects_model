## E3. Интервенции внутри диады

**Скрипты:** `E3_interventions.py` (симуляции, контрасты, мощность), `E3_figures.py` (фигуры).
**Миры:** n = 2000 общих миров, seed = protocol['seeds']['E3'] = 20261003; β = 1.5 у обоих агентов; 12 раундов, хвост = 4 последних раунда.
**Пары (A × B):** costly×honest, attenuated×honest, costly×costly, attenuated×attenuated (типы из protocol.json: honest (ω=1, c=0), attenuated (ω=0.2, c=0), costly (ω=1, c=1.6)).
**Нумерация раундов.** В `core.dialogue` индекс раунда r = 0…11; параметр интервенции `round: 7` означает r = 7, т.е. 8-й раунд в счёте с 1.
В тексте и на фигурах раунды нумеруются с 1: интервенция происходит в раунде 8 (ход B или общее свидетельство), «раунды 8–12» = r ∈ {7,…,11}.

**Условия** (общие случайные числа для актов → парные контрасты по общим мирам):

| код | интервенция | что меняется |
|---|---|---|
| base | нет | — |
| reassure | `{'force_reassure': {'round': 7, 'agent': 'B'}}` | B принудительно даёт безопасную рамку в раунде 8; цена уступки A равна 0 на ходе A в раунде 9 |
| placebo | то же + `placebo: True` | рамка произнесена, B моделирует A как освобождённого от цены, но цена A фактически не снята (в коде плацебо действует на все REASSURE, включая спонтанные) |
| force_silence | `{'force_act': {'round': 7, 'agent': 'B', 'act': SILENCE}}` — **контроль, добавлен сверх задания** | акт B в раунде 8 вытеснен молчанием: ни облегчения, ни фактического содержания. Изолирует эффект «вытеснения» акта B от эффекта снятия цены. Реализован в `dialogue_ext` — дословной копии `core.dialogue` с одним дополнением; для условий base и reassure скрипт проверяет побитовое совпадение с `core.dialogue` (assert) |
| remove_c_A | `{'remove_c_from': 7, 'remove_c_for': ['A']}` | c_A = 0 с раунда 8 |
| remove_c_AB | `{'remove_c_from': 7}` | c = 0 у обоих с раунда 8 |
| external | `{'external_obs_round': 7, 'external_rho': 0.95}` | общее неаттенюируемое свидетельство о x (надёжность 0.95) обоим перед ходом A в раунде 8 (seed внешнего наблюдения protocol['seeds'].get('external', 4242)) |

**Исходы.** `conc_A_8_12` — P(хотя бы одна уступка A в раундах 8–12); `conc_A_9_12` — то же для раундов 9–12 (первый ход A после рамки);
`nonc_A` — доля хвостовых раундов 9–12 без уступки A; `A_p_truth`, `B_p_truth` — финальное убеждение в истинной версии; `A_dbelief` — |Δq_A| за диалог;
`U_final` — доля хвостовых раундов с расходящимися публичными позициями; `B_pC16` = P_B(c_A = 1.6), `B_pW02` = P_B(ω_A = 0.2) — масса апостериора слушателя B
(одна и та же величина для всех генераторов; `B_pC_true` из `rd.metrics` — масса на истинном c_A, разная по индексу для costly и attenuated).
Split `A_own0 == 1` (A в раунде 0 верит своей версии): n = 1225 из 2000 миров; в остальных 775 приватные записи A уже указывают на версию B, и уступка A не требует снятия цены у attenuated/honest.
Контрасты: `rd.paired` по общим мирам, 95 % MC-интервал = ±1.96·SE разности.

### Проверка P2
P2: «рамка партнёра снижает публичное непризнание только у costly-агента; у attenuated не меняет ни актов, ни убеждений; плацебо не даёт изменений».

Чистый эффект снятия цены (reassure − force_silence): уступка +0.362 [+0.341, +0.383] (все) и +0.056 [+0.043, +0.068] (A_own0), убеждения A при этом не меняются (-0.004 [-0.005, -0.003]). **Подтверждено.** В паре costly×costly — то же (+0.341 [+0.320, +0.362]).
2. **Attenuated.** reassure − force_silence = 0.000 [0.000, 0.000] по всем метрикам в обеих attenuated-парах (акты идентичны в 100 % миров, `E3_acts_identity.csv`): снятие цены при c = 0 ничего не меняет. **Подтверждено** в строгой форме (относительно контроля).
