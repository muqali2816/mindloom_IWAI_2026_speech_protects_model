# METHODS — Трек 1: E1 (фазовая карта пар механизмов) и E4 (критерии временного режима)

Модель: reciprocal_dyad v0.7 (core.py / observer.py без изменений; правило ослабления `core.ATTENUATION = 'shrink'`).
Все величины — конструкты симуляции заданных механизмов; никаких утверждений о людях. Все числа ниже скопированы из results/*.csv.
Валидация перед запуском: `validate.py` — 10/10 проверок пройдено (регрессия к v0.6 бит-в-бит; см. оговорку о пути `--v06`).

### P1 — реципрокное усиление (results/E1_P1_reciprocal.csv, E1_P1_rank.csv)

Вывод P1: первая часть (максимум непризнания и скрытого сдвига у costly×costly; высокое непризнание при почти нулевом сдвиге у attenuated×attenuated) — **подтверждена на срезе both_own**.
Реципрокное усиление — **не подтверждено содержательно**: одиночный эффект nonc_A(costly×honest) = 0.998 уже у потолка, поэтому наблюдаемое совпадает с произведением (Δ ≈ 0) и превышает аддитивное предсказание лишь на 0.005–0.009 (при β=1.5, both_own интервал включает 0). Тест на потолке неинформативен. Для attenuated×attenuated при β=1.5, both_own превышение аддитивного предсказания +0.054 [+0.034; +0.073] — единственный надёжный супераддитивный эффект. На срезе `all` произведение независимых долей завышает ожидание (Δ отрицательные), потому что стартовые уступки A и B отрицательно коррелированы через скрытый факт.

### P4 — итог

- «Персистентность > 0.9 только в парах с хотя бы одним costly или attenuated»: **не подтверждена в заявленной форме**. both_own: > 0.9 требует, чтобы *оба* агента были не-honest (любой из attenuated/costly/mixed): attenuatedxattenuated, attenuatedxcostly, attenuatedxmixed, costlyxattenuated, costlyxcostly, costlyxmixed, mixedxattenuated, mixedxcostly, mixedxmixed; honest×attenuated 0.802, honest×costly 0.886, mixed×mixed 0.956. all: > 0.9 ⇔ хотя бы один costly; attenuated без costly — нет (0.810).
- «Гистерезис: частота уступок не возвращается за 4 раунда только у costly×costly»: **не подтверждена для частоты актов** (возврат к контролю ≤ 2 раундов во всех парах); **подтверждена в другой переменной** — расхождении публичных позиций, которое не возвращается ни за 4 раунда, ни к раунду 24, и не только у costly×costly, а во всех парах с c > 0 (сильнее всего у costly×costly).

## Отклонения и оговорки
- E4 выполнен на 24 раундах (разрешено заданием); хвостовые метрики core.metrics для E4 — последние 4 из 24; персистентность — по раундам 17–24.
- В E4 базовые условия запущены для всех 16 пар при обоих β; интервенция — для 16 пар при β = 1.5 и costly×costly при β = 0 (не для 16 пар при β = 0).
- Тест реципрокного усиления для costly×costly находится у потолка (одиночные эффекты ≥ 0.99) и поэтому неинформативен.
- Срез both_own содержит 488 (E1) / 477 (E4) миров из 2000 — интервалы соответственно шире.
- Дополнительно к заданию: модель (d) в прогнозе; интервенция для всех пар (нужна для «только у costly×costly» в P4); heatmap для β=0 и среза `all`.
- validate.py: путь `--v06` должен указывать на каталог с подпапкой `results/`; при передаче самой папки v06_results_for_regression две регрессионные проверки пропускаются (создана ссылка /tmp/v06shim/results → все 10 пройдены).
- npz-дампы диалогов не сохранялись (32+49 условий × ~6 МБ); все метрики по мирам — в CSV.
